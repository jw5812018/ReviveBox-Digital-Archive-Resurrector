# EchoShelf — Product

- Personal, local-first archive for bookmarks, RSS/Atom feeds and plain-text notes.
- Kiroween 2026 **Resurrection** track: revives personal web portals, directory-style
  collections and early self-hosted feed readers; bookmark HTML and OPML remain valid,
  living formats — never claim they are dead.
- Target users: developers, researchers and students who save a lot and refind too little.
- v1 boundaries: no accounts, no cloud sync, no AI features at runtime, no web crawling
  (feeds refresh only on explicit user action), no browser extension, no native mobile.
- UI copy is English; user content must fully support Chinese (continuous-text search).
  A full bilingual UI is out of scope for v1.
- Honesty: every visible button works; unfinished states are shown as such, never faked.
