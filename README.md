# ReviveBox Digital Archive Resurrector — EchoShelf

**EchoShelf brings your forgotten web back into view.** A Kiroween 2026
**Resurrection** track project: a personal, local-first archive that revives
personal web portals, directory-style collections and early feed readers.

## Where things live

| Path | What it is |
| --- | --- |
| `2026kirowen/` | The EchoShelf application (React + TypeScript + Vite, Node feed API) |
| `2026kirowen/README.md` | Setup, commands, deployment, feed-fetch rules |
| `.kiro/specs/echoshelf-mvp/` | Requirements, design and task specs (Kiro) |
| `.kiro/steering/` | Project steering rules used during development |
| `.kiro/hooks/` | Kiro hook configuration |
| `2026kirowen/docs/` | Development guide, build log, Kiro usage notes |

## Quick start

```bash
cd 2026kirowen
npm install
npm run dev
```

See [`2026kirowen/README.md`](2026kirowen/README.md) for the full command
list, production build and deployment notes.
